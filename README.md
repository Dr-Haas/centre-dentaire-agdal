# Centre Dentaire Agdal

Prototype de refonte du site Agdal Dental Clinic (blanc, noir et doré).

- `index.html` : maquette responsive interactive, avec logo Agdal intégré.
- `devis-dikio.html` : proposition commerciale DIKIO (2 000 € HT, options de contenus).

Les images de démonstration et les contenus médicaux sont à valider avant mise en production. Les fonctionnalités de réservation, CRM et CMS restent à développer. Le devis est une page accessible par URL directe, pas une page de navigation patient.
